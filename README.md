# Mesto

Интерактивный сервис для добавления и просмотра фотографий мест.

## Ссылка на проект

**https://mrwoxi.github.io/mesto-production/**

## Запуск в разработке

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Технологии

- Vite
- JavaScript (ES Modules)
- BEM
- REST API (mesto.nomoreparties.co)
